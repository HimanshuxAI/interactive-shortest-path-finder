How the route is found

Dijkstra's algorithm grows a settled region outward from the start, always finalising the reachable place with the smallest tentative distance. Because every campus road has a weight, that greedy choice is safe: once a place is settled, no later route can reach it more cheaply.

# dist = tentative cost from source, prev = where we came from
function Dijkstra(graph, source):
  for each place v in graph:
    dist[v] ← ∞ ;  prev[v] ← none
  dist[source] ← 0
  heap ← min-heap containing (source, 0)

  while heap is not empty:
    u ← heap.extract-min()            # smallest tentative cost
    if u already settled: continue   # stale duplicate
    mark u settled

    for each road (u → v) that is open:
      alt ← dist[u] + weight(u, v)
      if alt < dist[v]:            # relax the road
        dist[v] ← alt
        prev[v] ← u
        heap.insert(v, alt)

  return dist, prev                 # walk prev back from the target
Time
O((V + E) log V) with a binary heap — each road is relaxed once, each heap operation costs log V.
Space
O(V + E) for the distance and predecessor maps, the heap and the adjacency list.
Weights
Campus road lengths in metres. Walking time assumes a steady 1.3 m/s, so the time view is the distance view divided by 1.3 — same route, different unit.
Editing
Negative or zero weights are refused: Dijkstra assumes no road can make a route cheaper by being travelled. Duplicate roads and self-loops are refused too.

Where the same idea is used

Nothing about this algorithm is specific to a campus. Anywhere a network has costs on its links, the same settle-and-relax loop applies.

Campus route planning

Getting a first-year from a hostel to a 9 am lecture in the Engineering Block without crossing the whole campus — and knowing it is 7 minutes, not 12.

Maps and navigation

The routing engine behind turn-by-turn directions. Real road networks are far larger, so the heaps become A* searches with a distance-to-destination estimate.

Computer networks

OSPF routes packets by running Dijkstra over routers, using link cost derived from bandwidth instead of metres.

Transportation planning

Deciding where a new footpath or shuttle stop pays off: re-run the search and measure how much total travel time the new link removes.
